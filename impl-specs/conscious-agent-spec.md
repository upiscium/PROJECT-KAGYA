# ConsciousAgent 設計メモ

## 目的
情動状態と検索済み記憶を統合し、推論モデルに渡すシステムプロンプトを構築して応答を生成する。

## 公開インターフェース

### `ConsciousAgent`
- 推論モデルを操作する薄いラッパーとする。
- 依存として、生成モデルと記憶検索結果を受け取る。

### `build_prompt(valence, arousal, memory_context)`
- 現在の情動状態と検索済み記憶から、システムプロンプトを構築する。
- 出力はそのまま生成 API に渡せる文字列とする。

### `generate_response(prompt)`
- 構築済みプロンプトを使って推論モデルに応答を生成させる。
- 返り値は生成テキストとする。

## 入力ルール
- `valence` は快不快を表す。
- `arousal` は覚醒度を表す。
- `memory_context` は `DB1` / `DB2` の検索結果を含む整形済み文字列とする。

## プロンプトルール
- プロンプトには現在の `valence`、`arousal`、`memory_context` を明示する。
- `<think>` などの内部思考を促す指示は含めてもよいが、出力形式を壊さない程度に控えめにする。
- 役割は短く明確にする。

## 境界条件
- `memory_context` が空でも動作する。
- 情動値が範囲外でも、呼び出し側の仕様に従って扱う。
- 推論モデルが `<think>` を返さない場合でも応答生成は成立する。

## エラー時の挙動
- 生成モデルが失敗した場合は例外を返す。
- 入力型が不正な場合は明示的に失敗する。

## 仕様テスト観点
- プロンプトに `valence`、`arousal`、`memory_context` が含まれること
- 空の `memory_context` でも動作すること
- 生成失敗時に例外を返すこと
- 出力フォーマットが安定していること

## 非目標
- 完全な推論制御
- 内部思考の保証
- 記憶検索そのものの実装

## 補足
- このモジュールは、情動と記憶を推論モデルに橋渡しする役割に限定する。
