# Conscious Agent - Idea Review

## 対象
`conscious_agent.py`。情動と記憶を統合して推論モデルに出力させる案。

## 良い点
- 情動と記憶を一箇所で統合するので、応答の一貫性を作りやすい。
- 既存の reasoning model と相性がよい。
- prompt design だけで効果を試しやすい。

## 先行事例との近さ
- 典型的な system prompt orchestration に近い。
- reasoning model の内部思考を促す設計としては自然。

## リスク
- `<think>` 強制はモデルやテンプレート依存で壊れやすい。
- 情動をプロンプトに入れすぎると、雑音になる可能性がある。
- 長期記憶との整合性を毎回厳密にチェックすると遅くなる。

## 実現性
- 実現性: 中〜高。
- 難易度: 中。
- 工数感: 小〜中。

## 実装時の注意
- プロンプトは短く、役割を明確にする。
- まずは出力フォーマットの安定性を確認する。
- 内言の内容より、外部応答の品質を優先する。

## 結論
- 研究プロトタイプとしては有効。
- ただし、制御しすぎると不安定になるので、最初は控えめな指示がよい。
