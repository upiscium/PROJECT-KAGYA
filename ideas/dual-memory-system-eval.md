# Dual Memory System - Idea Review

## 対象
`dual_memory_system.py`。短期エピソード記憶と長期意味記憶を分ける案。

## 良い点
- 人間の記憶モデルに近く、説明しやすい。
- 会話ログをそのまま長期保存しないので、ノイズを抑えやすい。
- Retrieval と Consolidation の役割分担が自然。

## 先行事例
- `MemGPT` に近い階層記憶。
- `Generative Agents` に近い reflection / memory consolidation。
- 既存研究の延長線上で、アイデアとしてはかなり自然。

## リスク
- DB2 昇格条件が甘いと、幻覚を永続化する。
- 検索結果を混ぜすぎると、直近文脈と確定事実が混線する。
- 要約だけに頼ると、元の根拠が失われる。

## 実現性
- 実現性: 高い。
- 難易度: 中。
- 工数感: 小〜中。

## 実装時の注意
- `confidence` と `source` を必須にする。
- `DB1 -> DB2` は段階的に移行する。
- 検索は `DB1` 優先、`DB2` 補助の順が安全。

## 結論
- 中核機能としてかなり有望。
- 成否は「少なく正しく覚える」設計にかかっている。
